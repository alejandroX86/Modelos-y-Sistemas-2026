📋 Relevamiento del Dominio - Pizzería con 3 Sucursales

Descripción del Sistema

Sistema integral de gestión para pizzería con servicio de delivery que incluye:

  • Gestión de 3 sucursales (Central, Norte, Sur)
  • Sistema de facturación electrónico
  • Control de comandas en cocina
  • Gestión de delivery y repartidores
  • Control de stock e inventario
  • Atención al cliente y reservas

📝 Descripción del Flujo

  1. Inicio del Pedido: El cliente realiza el pedido por diferentes canales
  2. Registro: El mozo ingresa el pedido al sistema
  3. Tipo de Servicio: Se define si es local o delivery
  4. Preparación: Cocina recibe la comanda y prepara el pedido
  5. Control de Calidad: Se verifica que el pedido esté correcto
  6. Entrega: Según corresponda, se sirve en mesa o se asigna repartidor
  7. Pago: Se procesa el pago y se emite la factura
  8. Cierre: Se actualiza el stock y se cierra el pedido

📝 Explicación del Diagrama de Secuencia

Este diagrama muestra la interacción temporal entre los actores y el sistema para el caso de uso "Registrar Pedido con Delivery":

  1. Cliente → Sistema: Solicita nuevo pedido
  2. Sistema → Cliente: Muestra menú disponible
  3. Cliente → Sistema: Selecciona productos
  4. Sistema → Sistema: Calcula total y valida stock
  5. Sistema → Cliente: Solicita datos de entrega
  6. Cliente → Sistema: Ingresa dirección y teléfono
  7. Sistema → Sistema: Valida zona de cobertura
  8. Sistema → Repartidor: Notifica nuevo pedido disponible
  9. Repartidor → Sistema: Confirma disponibilidad
  10. Sistema → Cocina: Envía comanda para preparación
  11. Cocina → Sistema: Confirma recepción
  12. Sistema → Cliente: Confirma pedido y tiempo estimado
